# .github

Organization-level defaults for [@cpdotdev](https://github.com/cpdotdev).

- [`profile/README.md`](profile/README.md) — the public organization profile shown on
  <https://github.com/cpdotdev>. Edits land on the profile as soon as they are on `main`.

Anything added here (issue templates, `CONTRIBUTING.md`, `SECURITY.md`, workflow templates)
applies to every repository in the organization that does not define its own.
